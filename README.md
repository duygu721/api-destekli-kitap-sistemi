# 📚 API Destekli Kitap Sistemi

Java ile geliştirilmiş, **Google Books API** kullanarak kitap arama ve yönetme uygulamasıdır.

## ✨ Özellikler

* 📖 Google Books API ile kitap arama
* ➕ Kitap ekleme, güncelleme ve silme
* ⭐ Favori kitap sistemi
* 🔎 Kitap filtreleme
* 💾 TXT dosyasına veri kaydetme

## 🛠️ Kullanılan Teknolojiler

* Java
* Google Books API
* HTTP Requests
* TXT Dosyası
* CRUD

## 🔄 Çalışma Mantığı

```text
Kullanıcı kitap arar
        ↓
Google Books API
        ↓
Kitap bilgileri alınır
        ↓
Java ile işlenir
        ↓
Listeleme / CRUD / Favori
```
